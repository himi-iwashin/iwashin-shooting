# イワシんの海まもり大作戦

イワシんを動かし、泡で海ごみを片づけながら魚の仲間を助けるスマートフォン向けシューティングゲームです。

## 3つのステージ

1. **川の河口** — 森から流れ着いたごみを片づけ、「流れごみの大だんご」と対決。
2. **定置網の中** — 網にからまった仲間を助け、「からまり大網」の攻撃をかわして網をほどく。
3. **氷見の深海** — 深海のごみをまとった「深海ごみクジラ」と対決し、海を取り戻す。

ステージごとにごみの種類、海の色、ボスの姿と攻撃が変わります。敵の攻撃は赤く表示されます。魚に泡を当てても傷つかず、イワシんが触れると救出できます。
