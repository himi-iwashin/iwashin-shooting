# イワシんの海まもり大作戦

スマートフォンでも遊べる縦画面シューティングゲームです。イワシんを操作して泡を撃ち、海ごみモンスターを片づけながら魚の仲間を助けます。外部ライブラリ・サーバー処理は不要です。

## 公開URL

https://himi-iwashin.github.io/iwashin-shooting/

## GitHub Pages設定

リポジトリの **Settings → Pages → Build and deployment** で、Source を **Deploy from a branch**、Branch を **main**、Folder を **/(root)** に設定します。

## ARカメラとの連動

ARカメラからは次のリンクでゲームを開けます。

```html
<a href="https://himi-iwashin.github.io/iwashin-shooting/?from=ar">イワシんのシューティングで遊ぶ</a>
```
